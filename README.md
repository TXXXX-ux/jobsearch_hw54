В рамках этой части проекта была полностью переработана система безопасности приложения. Теперь доступ к функционалу сайта разграничен согласно техническому заданию.

Что было сделано:

Настройка Spring Security:
Внедрена поддержка formLogin и httpBasic для различных способов авторизации.
Отключена защита CSRF и настроены параметры frameOptions для корректной работы консоли.

Разграничение прав доступа:
Регистрация /api/users/register и просмотр вакансий доступны всем пользователям без исключения.
Создание вакансий POST /api/create теперь требует обязательной авторизации через Spring Security.

Интеграция с БД и Liquibase:
Добавлены миграции для создания таблиц authorities и управления ролями пользователей через Liquibase.
Настроено динамическое извлечение данных пользователя через CustomUserDetailsService.

Логирование:
В VacancyControlle и сервисах добавлены информативные логи, позволяющие отслеживать действия пользователей, например, создание вакансий конкретным юзером.

Как запустить и проверить:

Выполнить Maven Reload и запустить MovieRiviewerApplication.

Ссылка: http://localhost:4040/login

Тестовый вход:
Для проверки авторизации используйте логин tyler@fightclub.com и пароль test123.

Ссылки для проверки:
Главная страница: http://localhost:4040/
Swagger UI: http://localhost:4040/swagger-ui/index.html

Примеры JSON-запросов постмана
Для всех запросов, требующих авторизации, выберите вкладку Auth > Basic Auth и введите:

Username: tyler@fightclub.com

Password: test123

Регистрация нового пользователя
Метод: POST

URL: http://localhost:4040/api/users/register

Body (JSON):

JSON
{
  "name": "Tyler Durden",
  "email": "tyler2@fightclub.com",
  "password": "password123",
  "phoneNumber": "0555123456"
}

Создание новой вакансии (Требуется Auth)
Метод: POST

URL: http://localhost:4040/api/create

Body (JSON):

JSON
{
  "name": "Java Developer",
  "description": "Разработка систем на Spring Boot",
  "category": "IT",
  "salary": 1500,
  "expYears": 2
}
Примечание: Если не авторизоваться, сервер вернет 401 Unauthorized или перенаправит на страницу логина.

Получение списка всех вакансий (Доступно всем)
Метод: GET

URL: http://localhost:4040/api/vacancies
